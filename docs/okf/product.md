# 产品定义

GImage 让管理员以账户和每日美元额度为边界，为成员提供图片、视频和音乐生成服务；生成结果自动进入用户自己的资产库。

## 核心用户与任务

| 用户 | 主要任务 | 可访问范围 |
| --- | --- | --- |
| 创作者 | 发起生成、延续图片会话、下载和删除自己的资产 | 自己的内容与额度 |
| 管理员 | 创建账户、分配额度、查看总用量和内容记录 | 全部账户与内容 |

## 产品原则

1. **私有且可控**：密钥只在服务端，输出落在本地文件系统。
2. **成本可见**：模型定价、每日可用额度和每条创作成本对用户可见。
3. **会话连续**：图片创作可沿会话带入上下文或上一张结果。
4. **失败不扣费**：服务端先原子预扣，只有成功完成后才结算；失败任务释放额度。
